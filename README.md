# Partnership & Sponsorship Studio

A customizable message generator for partnership proposals, sponsorship outreach, and professional communication. An independent project by Burcu Aydın, with a Turkish-language interface and templates.

## Features

- 14 communication scenarios with three message alternatives each.
- Friendly, balanced, and formal tones, with short and detailed versions.
- Email, LinkedIn, and direct-message formats.
- Optional organization name and customizable sender information.
- Editable messages, clipboard copying, and text-file downloads.
- Responsive pink, cream, yellow, and lavender design.

## Run locally

Open `index.html` in a browser. No installation, build step, API key, or backend is required. Clipboard access may depend on browser permissions; manual copying remains available.

To run the template checks with Node.js:

```sh
node checks.cjs
```

## GitHub Pages

In the repository's **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Privacy and limitations

Messages are generated locally from predefined templates, not an AI service. The application does not automatically send messages or submit form data to a server. Drafts are not persisted after closing the page; download any messages you want to retain. Review names, dates, requests, and commitments before sending. Example contacts are illustrative.
